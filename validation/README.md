# 部署验证口径

本目录记录打包后的接口兼容性检查，不替代历史成绩，也不是新的十任务各100回合测评。

- `deployment-summary.json`：各任务离线前向、动作形状、回合重置和完整环境回合是否完成。
- `*-load.json`：使用合成RGB输入进行真实模型推理，动作必须为有限值的50×14数组；不能据此推断任务成功率。
- `*-environment.json`：官方评测程序输出的完整回合记录。三个自训任务各2回合、七个官方任务各1回合，共13回合。
- `unit-tests-final.log`：实际云端Python/CUDA单元测试。跳过项是需要本机历史源码的对照测试。
- `windows-unit-tests.log`：本机历史图像/动作源码对照和无需GPU的测试；本机没有torch/cv2，相关测试已明确跳过。

环境回合检查使用公开random设置、seed=0，为限定启动验收时间关闭了专家可达性筛选；这与正式100回合测评口径不同。提交默认配置仍开启专家筛选。超时的策略失败与程序运行异常严格区分。

推理使用随包本地模型、分词器和RGB预测器，开启Hugging Face与transformers离线模式，不调用外部模型API。已有仿真资产来自云端安装环境，不等于从空系统离线安装成功。NoMaterial机器人视觉资产差异和标准环境复验要求见根目录`README-submit.md`。

历史成功率的原始依据另存于`provenance/`。文件夹名的成功率不是本目录小样本检查的新结论，不应平均成一个十任务总体成绩。
