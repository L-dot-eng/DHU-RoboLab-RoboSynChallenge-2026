# 按铃84% RGB预测mask＋有限补按更新

此更新必须叠加到原完整 `RoboSyn十任务.zip`，不是独立运行包。原包其他九个任务、共享VLM、依赖和资源不变。

1. 先解压原完整包，得到 `RoboSyn十任务_抽屉65_提篮54_移液器49_SmolVLA/`。
2. 将 `ClickBell_84_RGBMask_Recovery_增量.zip` 解压到同一个父目录，合并其中同名目录并覆盖更新文件。不要解压成嵌套的第二层同名目录。不需要先安装72%增量包；两份增量包互为备选，只选择一份。
3. 进入该目录，运行 `python verify_bundle.py`，应报告全部文件校验通过。
4. 按 `README-submit.md` 准备官方Python3.11/EmbodiChain0.2.4环境，运行 `bash eval.sh click_bell random 0`。

新增 `checkpoints/click_bell_72pct_ours/policy` 和 `predictor` 必须一起保留；目录名72标识未改变的基础权重，本次84%版本没有重训它们，也不是将预测mask喂给官方35%权重。默认路由为 `clickbell_rgb_mask_recovery`。前100动作沿用SmolVLA的50预测/50执行；之后才可进入局部补按，每次生成并执行50个平滑目标，最多五次。

补按只使用RGB预测可见性、机器人关节状态/运动学与动作历史。参考点是原按压窗口内测得的最低右手TCP位置，这是接触启发式，不是从RGB精确还原的铃三维位置。尝试中心及X/Y方向±4mm，接近参考点上方6mm，再按到其下方3mm，保留关节限幅、FK验证和不可用时回退。左臂及夹爪在补按期间保持此前动作，不修改成功条件或物理参数。

独立100个可行随机场景按官方超时优先口径为84成功/16失败：77次在前100步成功，7次在补按动作期间成功。原始日志另有1次在第361步同时出现成功谓词和超时，官方规则计失败，原始日志85计数保留但不用于命名或提交成绩。不能把84%-72%的12个百分点差值全部归因于补按；两组不是严格相同输入的配对测评。完整记录与协议差异见 `validation/clickbell84/README.md`。此成绩不保证正式隐藏测评表现。

旧完整ZIP没有修改，单独使用旧ZIP仍然选择官方35%按铃版。更新后其余九项路由不变，旧按铃权重也没有删除；需要回退时使用原ZIP重新解压。
